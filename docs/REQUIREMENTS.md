## R1. 下载功能

### R1.1 各内容加下载按钮
- 小说、漫画、动漫、图集——提供下载按钮。

### R1.2 下载粒度
- **小说**：**单章下载** 或 **多章下载**（可勾选章节）。
- **动漫**：**全部下载**（整片/整话）。
- **图集**：**全部下载**（整套）。
- **漫画**：多张图 → **打包下载**（见 R1.6）。

### R1.3 画质选择（**仅动漫**）
- 默认下载**最高画质**。
- 档位【SPS 实测】：

  | 键 | 真实分辨率 | UI 俗称 |
  |---|---|---|
  | `720` | **1280×720** | 720P（最高，默认） |
  | `240` | **≈426×240** | 低清（用户此前记作 "480P"） |
  | `intro` | —— | 预告片 |

  > ⚠ 用户日志称档位为「480P / 720P」，但**实测低档是 240p**（键名 `240`）。

### R1.4 下载时显示下载链接（三条，均可复制）
1. **加密链接**（CDN 原始密文地址）
2. **解密密钥链接**（如动漫的 `key.php`）
3. **解密完成后的链接**（合并/解密后的产物）
- 均可**一键复制**。

### R1.5 下载完成后转 MP4
- 动漫（HLS 分片）下载完成后 **→ MP4**，**客户端内置 FFmpeg** 执行。

### R1.6 图片类（漫画 / 图集）下载方式
- **直接下载图片**，无需转格式。
- 一本漫画 / 一个图集**含多张图**时 → **直接打包下载**（zip 之类）。

### R1.7 动漫多集聚合 + 全集/单篇下载（新增）
- 一个动漫**"一篇"里含多集**（多 `season` / 多 `ep`）→ 展示时**整合在一起**
  （按 `series` 归为一组，按 `season` → `ep` 排序）。
- **下载时显示两种选项**：**下载全集**（该系列全部集）或 **下载单篇/单集**。
- 【数据支撑，实测】详情 `v2/combine/animat/internal/{id}` 的 `directory[]` 每项含
  `season`/`ep`/`id`/`avkey`/`series`；`v2/animat/series` 可列出系列条目。
  例：id=14004「不当哥哥了！」→ 12 集；id=69「淫妖虫」→ 2 季。
- （类推）漫画同一 `series` 的多话同理可聚合。

## R3. 独立账号系统 + 管理后台（自建）

> 后端部署在 Cloudflare 上；**形态哪个方便用哪个**（Pages / Workers 均可）。

### R3.1 自建账号 = 强制门禁
- **必须先注册自建账号，才能进入软件**；进入后再登录 **MMLU 官方账号**。
- **没有自建系统账号 → 无法使用软件**（硬性前置）。

### R3.2 注册 / 登录
- 注册仅需 **用户名 + 密码 + 邮箱**。
- **邮箱不发验证码**，**仅作记录**。
- 登录（用户名 + 密码）。

### R3.3 使用统计
- 后台可查看：**注册人数** + **在线人数**。
- **"在线人数"口径**：**当天登录过** 且 **使用软件 ≥ 5 分钟** 的人
  （即：当日登录 + 有效使用时长 ≥5min 才计入；多久刷新待实现时定）。

### R3.4 封号系统
- 封号 = **无法使用软件**。
- 被封后进入软件显示：**解封剩余天数**、**封号原因**、**申诉渠道**。
- **封号类型由后台设置**：支持 **有限期封号** 与 **永久封号**。
- **申诉渠道 = 邮箱。**
- 自建账号被删/被封**不影响**其内部 mmlu 官方账号的本地凭据（不连带清除）。

### R3.5 系统代号说明
- **"卡密系统" 只是该后台的一个「拟称」（暂用代号），不是昵称，也不是系统的正式名称**；
  **不含卡密/授权码激活功能**。

### R3.6 后台相册上传（新增，可选）
- 后台**相册自动上传**。
- **此项可有可无**（非必需）。

## 可行性备注（已实测，供后续实现参考）

| 内容 | 加密链接（密文直链） | 解密密钥链接 | 解密后 |
|---|---|---|---|
| 动漫 | `https://na.mmlu1.site/apen/<avkey>/ts/<avkey>-N.ts`（HLS 多段 + m3u8） | `https://na.mmlu1.site/apen/<avkey>/key.php`（16B ASCII key） | AES-128 解密 → 合并 TS → **FFmpeg 转 MP4** |
| 漫画(ns) | `https://ac1.mmlutech.xyz/<page_path>` | 无独立链接（固定 `nsComic*`） | AES-256 解密 → JPEG → 打包 |
| 漫画(av) | `https://ac1.mmlutech.xyz/<image_path>` | 无独立链接（逐图 b64 key/iv） | AES-256 解密 → JPEG → 打包 |
| 图集 | `https://ac1.mmlutech.xyz/<image_path>` | 同上（逐图 b64 key/iv） | AES-256 解密 → JPEG → 打包 |
| 小说 | `https://fiction1.mmlutech.xyz/<filepath>` | —— | 明文 UTF-8，无需解密 |

> 小说按 `filepath`（简）/`filepath_tw`（繁）直取，**单章=单文件**，多章=批量取多文件。
